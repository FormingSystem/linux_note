# 第1章\_泰山派RK3566旧版Linux\_SDK构建路线

这里整理 `tspi_linux_sdk_repo_20240131.tar.gz` 相关的历史构建记录，目标是学会把资料身份、宿主工具、板级选择和构建产物连成可追溯过程，并能从真实失败日志定位阶段。它不承诺覆盖所有泰山派修订或新版 SDK；原图与 2025-09-07 日志继续作为历史观察保留，新增检查与未完成的整套构建、实物验证明确分开。

## 1.2\_材料和相关专题

三个 C 文件和 SquashFS 补丁位于 [materials](materials)，正文提供完整内容与操作顺序。C 实验只需宿主 GCC，不依赖开发板；SDK 命令需要相应旧版本工作树，图中的电压值不能代替实物原理图核对。

板级硬件描述的通用机制见 [设备树专题](../../../../../knowledge/driver_model/device_tree/大纲.md)；引导阶段与镜像知识见 [U-Boot专题](../../../../../knowledge/system_software/uboot/大纲.md)。本文保留泰山派案例的具体配置、图像和错误证据，不把平台日志提升为所有 Linux 系统的构建契约。
