# 第1章\_全量目录重构记录

本文保留早期目录重构的归属决策，不作为当前完整文件清单或工具测试报告。后续专题继续拆分和移动，当前入口见 [内容索引](../../atlas/indexes/content_index.md)，持续正文重构的范围与验证记录见 [重构记录](repository_textbook_refactor.md)。

## 1.1\_重构依据

本次目录重构依据[仓库信息架构设计](../architecture/repository_information_architecture.md)执行，目标是建立知识本体、工程应用、平台差异、实践验证、研究证据、导航编排和仓库治理的稳定边界。

## 1.3\_链接维护

原记录采用 `git mv` 组织路径变化。当前维护仍须在提交前检查 Git 能否识别预期重命名，并使用链接工具核对 Markdown、图片和已支持的 Obsidian 配置路径；工具只改可确定的目标，拆分后一对多的入口与标题片段要逐项判断。写入后再扫描，确认没有剩余更新或新断链。

下面保留当时列出的检查目标值，**不是 2026-10-18 重新执行全部迁移所得的日志**：

## 1.4\_后续治理

当时对正式文档补充 `id`、`title`、`kind`、`status` 和 `domains`，保留正文阅读序号。当前 skill 和宿主配置不套用正文元数据；后续治理方向如下，其中学习路线已经存在，出版清单仅在真实工程需要时建立：

1. 将理论数据结构与 Linux 数据结构实现进一步拆分。
2. 将通用机制正文从领域应用文档中去重。
3. 建立 `atlas/tracks` 学习路线和反向索引。
4. 建立 `publications/manifests` 出版物编排。
5. 保持正文阅读序号，并在出版构建中校正跨文档连续性。
6. 增加孤立文档、依赖关系和源码版本检查。
