# 独立讲解与官方资料溯源

专题同时承担 **独立概念讲解** 与 **官方资料阅读指导**，不是手册目录翻译，也不是带参考书目的自说自话。学习顺序由读者的概念依赖决定，查询顺序由官方目录提供；正文负责把两者对应起来。

## 在概念旁给出能继续查阅的证据

对核心概念的首次定义、关键机制规则、容易混淆的边界，以及决定实现或部署选择的结论，在紧邻段落或所属小节给出“官方对照”。同一小节共享一组依据时可以合并，不要求每句话附链接，也不能只在全书末尾列出资料名称。

每个对照入口应使读者知道：

| 信息 | 写作要求 |
| --- | --- |
| 哪份资料 | 官方文档名称、文档编号和版本或修订号；本章首次引用时交代身份，后续可使用已经解释的短名 |
| 哪个目录位置 | 章节号与官方原文标题；按需补充图表号、寄存器/字段条目或稳定网页锚点，不能只写“见手册” |
| 怎样到达 | 链接到官方章节或仓库已有资料台账的精确入口；下载型资料保留版本与目录定位，不依赖本机绝对路径或不稳定下载地址 |
| 带着什么问题读 | 指出本段结论对应的定义、状态转换、字段条件或限制，以及继续阅读可确认什么；不让读者在长章节中自行猜测依据 |
| 证据适用到哪里 | 说明当前引用支持的是架构规则、具体实现还是平台配置，不能从一种证据跨层推出另一种保证 |

需要页码时区分 **文档印刷页码** 与 **PDF 文件页序号**，注明实际采用哪一种；网页没有页码时使用其真实标题与定位方式。页码是辅助入口，不代替文档版本、章节号和原文标题。只有整章确实作为概览来源时才引用整章；支撑具体条件的引用应继续收窄到相应小节或条目。

## 先核对身份与原文，再提炼解释

- 先核对所读资料的发行者、编号、版本和实际目录，再引用对应位置。不同修订的章节、图号或页码不能混用；打不开或尚未核对时明确标记未核对项，不凭记忆补出定位信息。
- 术语、寄存器和字段的正式英文名称以对应版本原文为准；便于理解的中文释义或功能描述可以补充，但不能冒充官方全称，也不能仅按符号拼写反推名称。
- 显式区分 **规范要求、实现选择、芯片或板级集成事实、教学推演/示例、实验观察**。教学阶段编号、类比和自绘图说明其整理性质；实验结果标明环境与覆盖边界；推论列出成立条件，不借一个引用包装成规范原话。
- 先用自己的因果解释讲通，再用原文作证和引导纵深。官方资料的目录顺序不直接决定章节顺序，未在本次范围内逐行核对的实现或未实测的平台能力不能写成已经完成的证据。

## 两条阅读路径分别验收

1. **断链阅读：** 隐藏链接后，读者仍能解释概念是什么、为何需要、与谁相连、和相邻概念有何区别，并复述本章关键过程。详细问题沿用 [断链阅读测试](reader_continuity_review.md#断链阅读测试)。
2. **溯源阅读：** 从本次新增或修改的关键概念、边界结论和实现选择旁逐项检查引用，确认文档身份、目录标题与内容相符，并能说明应查看什么规则或条件。链接可以打开但内容不支持结论，仍不合格。

两者不能互相抵消：讲得清楚不能免除证据，引用准确不能代替讲解。密集的下载台账、全字段覆盖表和审计记录保留在参考或研究层；正文只保留当前阅读任务需要的精确对照。

## 外部图表落地与教材自足

本条适用于本轮新写、补充或修复中承担推理职责的外部图表。先从正文结论反查依赖：如果理解结构、状态转换、时序、数值计算、比较或练习答案需要看某张图、某些表项，就把必要内容作为正文交付的一部分；已有“断链阅读”要求不能只落实为增加更多来源定位。

**图表补齐的前置门禁：** 本节的图表及下一节的寄存器表，先服从“背景与具体缺口 → 职责或设计选择的理由 → 能做什么及一次完整过程 → 表格比较或细化”的认识顺序。即使本轮任务是补图、补表，也先检查对象是否已经建立；在获准内容修改的范围内补齐缺口，仅排版授权下则记录缺口，不借此改写技术内容。

1. **从具体缺口引出对象：** 表格出现前，正文应说明现有方案已解决什么、参与者遇到什么仍未解决的问题，以及问题怎样发生。“为便于查询”“下面是手册参数”“该模块很重要”只是排版引语，不是背景与因果解释。
2. **区分职责与实现选择：** 说明该职责改变了哪一段因果链、为何能解决当前缺口。硬件上必须保留某种状态或完成某种通信，不等于某产品必须采用某种物理分块；物理布局、共享范围和接口组织要用实际约束及产品证据解释。教学推导只说明在给定条件下为什么合理，不能编造唯一设计方案或未经证实的历史起因。
3. **先闭合一次过程：** 用同一场景说明对象能做什么、不能代替谁，以及输入、状态归属、动作、输出和完成条件怎样衔接。可以配合关系图或时序图讲解，但不能把职责清单或字段表当成运行过程，让读者自行拼接。
4. **再交给表格精确化：** 表前说明读者现在要比较或查明哪一项，表格据此补充精确数值、位域、编码、条件或并列差异；读表后应用其中必要信息完成一个判断。无需把每个数值重写成散文，也不为满足顺序重复前文已经建立的机制。
5. **分别做两种冷读：** 暂时隐藏表格，读者仍能依据正文与说明性图解解释模块为何存在、怎样工作及作用边界；恢复表格后，能说出它新增了什么精度或比较依据。随后再隐藏外链与原手册，检查当前计算、操作与练习是否能完成。两项分别检查因果解释和资料自足，不能互相替代。

例如说明为什么需要按核区分私有中断状态时，可以先用两个核各自的定时器事件说明：若把同号来源混成一份待处理状态，就无法分别记录哪个核还有请求、哪个核已处理；因此需要按核区分来源及状态，再沿一个核的请求、确认和状态更新走完概念层的一轮。进入具体产品以后，先查明哪些物理模块保存这些逐核状态、哪些逻辑承担处理职责、怎样连接核侧接口，然后再解释容量和接口参数。中断类型、架构功能角色和产品物理块分别命名，不能因为名称相近就视为同一个对象；按核区分状态也不推出每核独立放置一个物理块。具体映射按 [概念到实现的映射与输入输出](concept_implementation_mapping.md) 建立。

- **就地呈现：** 在第一次需要据图表推理的位置，嵌入可使用的原图，或呈现必要范围的裁剪、表项重排、准确重绘。配套图表应在正文直接可见；仅提供附件下载、手册页码、外链或“自行查表”不算完成。未承担当前推理的完整目录、无关行列及后续机制，不机械搬入正文。
- **先带读，再归纳：** 图前说明当前问题与观察目标，图旁或图后带读者沿关键节点、箭头、行列或数据完成一次具体推导。说明适用的单位、位宽、索引或坐标范围、有效条件、版本及图例；结构图还要区分实际连接、逻辑关系、控制作用与状态归属。图不是正文解释的替代品，图注也不能只重复标题。
- **完整保留必要条件：** 裁剪或重排时保留决定当前结论的表头、单位、注释、例外和前置条件，标明范围与省略内容；不能只摘有利数据、丢掉限定脚注，或把特定实现画成通用规范。重绘仍须对照原件核对对象、方向、条件与数据；事实图与教学假设分别标注。
- **按授权选表达：** 有明确适用的授权或许可时，可以在允许范围内复制原图，并保留要求的出处与声明。没有明确再分发依据时，依据核实的事实原创组织结构图、时序图或数据表，不描摹原图的独创表达；标明“依据某版本资料重绘／整理”。署名和链接本身不产生复制许可，也不能以无法直接复制为由省去必要讲解。
- **按可读性安排尺寸：** 不设固定图片尺寸、文件大小或图表数量上限，也不以“图太大”省略理解所需内容。根据阅读任务选择完整图、局部放大或拆图，拆分时保留共同对象和连接关系；不得把文字缩到无法辨认。只引入解释所需内容，不把整本手册搬成教材。
- **核对覆盖而非凑图：** 对本轮涉及的外部图表保留工作型覆盖台账，记录“本地结论或练习 → 来源版本与图表／条目位置 → 本文呈现位置及资产 → 原图／裁剪／重排／重绘方式及授权依据或事实来源 → 条件保留与读图核验结果”。同一已落地表示可覆盖多个结论，不为数量重复画图。交付时提供台账位置和未覆盖项；不得把登记来源但未在正文兑现的项目记为完成。
- **逐项冷读：** 隐藏外链与手册后，只使用已约定的前置知识、本文图表和说明，逐项推导对应结论及练习答案。仍需回原文找连接、关键行列、单位或条件即未通过；回到缺口处补内容。再对照原件检查准确性，并实际预览图表的清晰度与标注，不能用链接检查或图形语法通过代替这两项验收。

台账留在工作记录或验收材料中；正文保留直接参与认识过程的图表、说明和就近出处。来源溯源支持核验，不能承担当前讲解缺失的步骤。

## 寄存器与寄存器组的本地查用表

正文开始实际解释、比较、计算或操作某个寄存器／寄存器组时，在首次讲解处或该组集中说明处提供本地表格，使读者无需翻手册就能理解本节读写。仅作为后文预告的名字不要求提前展开；正式使用时不能以名称清单、地址截图或外链代替可读的表与解释。

按本节所用范围组织表格，可以把寄存器位置表与字段表分开，但须覆盖以下信息：

| 信息 | 必须交代的事实 |
| --- | --- |
| 身份与接口 | 寄存器名称、所属逻辑接口及当前用途；接口归属不直接等于物理模块位置 |
| 定位与访问 | MMIO 给出偏移及所加基址的类型，平台实际基址由集成资料确认；系统寄存器给出正式访问名及所需访问方式，不杜撰 MMIO 地址，不把两种访问空间混为一表中的同一种地址 |
| 宽度与访问属性 | 寄存器宽度及适用的访问宽度、只读／只写／读写等属性；不同字段有不同属性时在字段行单独说明 |
| 当前相关字段 | 字段名、位号或位域、相关编码／取值及含义；读写条件、作用范围、读写效果和副作用，包括本次依赖的清零、置位、确认或完成语义 |
| 版本与裁剪范围 | 对应资料版本、章节及可用的页码／条目位置；明确只展开哪些相关字段，遗漏部分不被误读为不存在或可任意写入 |

数组或成组寄存器还应给出索引含义、元素步长、有效范围以及偏移／位号的计算关系，并用本节一个实际编号完成算例；有实现数量、访问权限或版本限制时一并给出，不能只留一个未解释的 `n`。无固定步长或采用编码选择时按真实规则说明，不强造线性地址公式。

不强制复制未使用字段的全集，但裁剪不得省去决定当前操作是否合法的保留位、写入条件或副作用。表中区分规范定义、实现选择、平台地址与教学示例；来源定位保留在表旁，当前判断所需的字段解释写在正文。将寄存器表及算例纳入上一节的覆盖台账与断链阅读，不能因为已经附上手册页码而跳过。
