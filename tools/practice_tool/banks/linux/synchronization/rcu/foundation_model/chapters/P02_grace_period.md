# 宽限期究竟等待谁

## 有边界的旧读者集合

更新者只需要覆盖入口切换前已经可能取得 A 的读者。切换后的新读者只能从入口取得 B，不影响旧对象回收，不应被无限纳入本轮等待。

因此宽限期不是固定延时，也不是等待系统出现绝对无人读取的瞬间。它证明一个有边界的旧读者集合已经全部越过安全点。

## 为什么固定时间不够

读者执行时间受抢占、中断、调度和负载影响。等待某个经验时长不能证明所有旧读者已经退出；时间到了仍可能有读者持有 A，时间过长又浪费回收机会。

```text
入口切换前取得 A → 属于本轮旧读者
入口切换后取得 B → 不属于本轮等待
旧读者全部越过边界 → 宽限期完成
```

## 本章结论

宽限期完成是一条关于旧读者集合的证据结论。下一章讨论为了获得这条结论，系统把原本读侧的成本转移到了哪些路径。
