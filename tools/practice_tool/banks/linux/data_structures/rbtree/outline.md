# 红黑树学习地图

## 第一阶段：看见普通搜索树的边界

### 第一章：正确的 BST 为什么仍会越来越慢

从连续插入造成的退化现场出发，区分“搜索结果正确”和“路径长度受控”。本章留下的问题是：能否在不破坏有序性的前提下改变树形？

## 第二阶段：推导可用的局部动作

### 第二章：旋转怎样改变形状而保持有序

从关键字区间而不是旋转口诀出发，证明局部父子重排保持中序顺序。本章留下的问题是：什么时候必须旋转，什么时候只需调整结构编码？

## 第三阶段：从局部规则得到全局保证

### 第三章：红黑约束怎样换来有界高度

把红节点理解为多路节点的二叉编码，把黑高理解为路径预算，解释红黑树为何允许局部不完全平衡。
