# 冲突、负载与复杂度边界

## 冲突不是异常

有限桶承载更大的可能键空间时，多个键映射到同一桶是必然事件。链式哈希把冲突对象连接起来，因此实际查找成本由哈希计算、桶定位和桶内比较共同组成。

平均常数时间不是无条件承诺。它依赖哈希函数能够把当前输入较均匀地分散到足够多的桶中。如果对象数增长而桶数不变，负载因子上升，桶内链逐渐增长，查找优势会被局部扫描吞噬。

## 输入分布也是约束

普通业务输入可能接近均匀，攻击者控制的键却可能故意制造碰撞。工程设计需要区分可信输入与不可信输入，并决定是否需要随机化、抗碰撞哈希或其他结构。

## 选择边界

哈希表擅长等值查询，不保存全局顺序。范围查询、最小值和相邻元素需要额外结构。下一章将冲突链映射到 Linux 的嵌入式 `hlist`，观察内核真正优化的对象布局和删除路径。
