# 第1章\_ADR\_0002\_采用本地优先持久化

## 1.1\_状态

`accepted`

## 1.2\_背景

训练答案、笔记、复习状态和知识源路径具有隐私属性。工具需要在无账号、无网络时继续训练，并保持可独立拆仓。

## 1.3\_决策

训练数据默认只保存在本机。结构化业务数据使用 IndexedDB 或受控本地服务，`localStorage` 只保存少量偏好和迁移标记。多设备同步不是默认能力，启用前必须另行设计服务、加密、冲突和删除传播。

## 1.4\_替代方案

- 默认云端账号：同步方便，但引入身份、服务成本和隐私边界。
- 全部使用 `localStorage`：实现简单，但事务、容量和迁移能力不足。
- 文件直接保存：便于备份，但浏览器权限和并发写入复杂。

## 1.5\_后果

- 必须提供可靠导出、备份和迁移。
- 浏览器数据清理可能造成数据丢失，需要显著提示。
- 多标签页需要租约和修订冲突处理。
- 未来同步必须显式启用，不能静默上传本地数据。
