# 第1章\_ADR\_0004\_AI\_草稿必须经过人工审核

## 1.1\_状态

`accepted`

## 1.2\_背景

AI 可以加速材料提炼和问题生成，但可能遗漏边界、伪造答案、误解版本、复制无关内容或受到知识正文提示注入影响。

## 1.3\_决策

AI 只能生成 `draft` 或 `needs_review` 内容。发布前必须由用户审核主题主线、核验答案、开放问题、拓扑关系、版本边界和原文引用。AI 不拥有工具权限，知识正文作为不可信数据处理。

## 1.4\_替代方案

- 自动生成并发布：速度快，但错误和引用风险不可接受。
- 完全禁止 AI：安全简单，但失去提炼效率。
- 只审核部分答案：无法保证未审核段落不会影响训练结论。

## 1.5\_后果

- 需要审核界面、差异视图和发布权限。
- 保存模型、提示、输入摘要和审核记录。
- 没有人工确认时内容不能进入正式训练目录。
- 远端模型处理必须由用户明确授权。
