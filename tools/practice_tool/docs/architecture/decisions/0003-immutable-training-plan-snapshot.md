# 第1章\_ADR\_0003\_冻结不可变训练计划快照

## 1.1\_状态

`accepted`

## 1.2\_背景

训练内容和用户模块会更新。如果进行中的会话总是读取最新题目，刷新后可能出现题目、顺序、答案框架和评分标准变化，历史结果也无法比较。

## 1.3\_决策

创建训练会话时冻结确定的训练计划版本和足以重放原训练的内容快照。已发布计划不原地修改；内容更新产生新版本。再次训练由用户选择原版本或最新版本。

## 1.4\_替代方案

- 始终读取最新内容：维护简单，但破坏恢复和历史可比性。
- 只保存计划版本号：若旧内容不可获得，仍无法重放。
- 复制整个知识库：存储和版权边界不可接受。

## 1.5\_后果

- 需要内容摘要、版本和快照清理策略。
- 历史比较必须显示计划版本差异。
- 知识源失联时，冻结训练仍能运行，但原文入口可能不可用。
- 永久删除旧版本前必须检查会话和复习引用。
