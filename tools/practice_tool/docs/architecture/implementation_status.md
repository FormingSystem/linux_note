# 第1章\_回路实现状态与版本边界

## 1.1\_文档职责

本文是设计与代码之间的实现状态单一事实来源。产品设计文档描述目标行为，本文件记录当前代码已经兑现的能力、部分兑现的约束、尚未实现的能力和验证证据。不得因为页面出现入口就把占位页视为功能完成。

当前基线对应 `tools/practice_tool` 的 `0.1.0` 开发版本，更新时间为 2026-07-26。

## 1.2\_当前可用主流程

```mermaid
flowchart LR
    L[大厅] --> LIB[训练库]
    LIB --> D[单元详情]
    D --> S[创建或恢复会话]
    S --> LEARN[专题学习]
    LEARN --> GUIDE[提示提问]
    GUIDE --> MODEL[脱稿输出]
    MODEL --> CASE[专业案例]
    CASE --> SUMMARY[训练总结]
    S --> L
```

当前提供 RCU、红黑树和哈希表三本专题电子书，共 12 个学习章节和 12 个训练任务。单元由 `banks/index.json` 和统一协议发现，页面没有按专题硬编码分支。

用户还可以从本机选择多个 Markdown，按“原文阅读”或“专题电子书”模式生成本地电子书。两类用户书籍保存在 IndexedDB，不直接写入仓库 `banks/`；已发布书籍显示在训练库的“我的电子书”区域。

## 1.3\_已经实现

### 1.3.1\_应用导航

- 大厅、训练库、单元详情、我的训练和训练会话已经使用独立路由。
- 主导航提供大厅、训练库、我的训练、复习、历史、知识源和设置入口。
- 桌面端使用单行应用栏统一承载产品标识、一级导航、运行状态、页面级操作和日夜主题切换；窄屏优先隐藏低优先级状态，手机宽度才将导航降为第二行。
- 用户没有保存手动主题时，应用读取并实时跟随操作系统 `prefers-color-scheme`；用户点击日夜开关后才保存显式覆盖。页面同时设置 `color-scheme`，使表单和滚动条等浏览器原生控件使用一致主题。
- 日夜主题的正文、目录、训练卡片、表单、检查项、提示、错误和交互状态统一消费主题变量；夜间覆盖位于共享 hover/active 规则之后，防止鼠标经过时被后声明的浅色背景反向覆盖。
- 训练页提供返回大厅入口。
- 浏览器前进、后退和刷新可以按照 URL 恢复页面。
- 无效顶层路由返回大厅；不存在的单元和会话显示错误状态。

### 1.3.2\_训练会话

- 新会话保存完整训练内容快照，不随题库当前内容静默变化。
- URL 使用会话 ID、阶段和稳定题目 ID，不使用数组序号。
- 专题学习、提示提问、脱稿输出、专业案例和训练总结都可以从步骤栏直接进入。
- 每个阶段保存上次停留的稳定题目 ID；切换阶段时恢复各自位置，阶段访问不等于完成。
- 学习阶段由 `book.json`、`outline.md` 和 `chapters/` 驱动，支持书籍大纲、章节目录和连续 Markdown 正文。
- 桌面阅读页提供全书目录、连续正文和本章标题目录；移动端退化为单栏。
- 电子书阅读页的章节目录和本章目录可以独立收起；章节标题目录使用稳定锚点跳转，并使目标标题对齐正文视口顶部。
- Markdown 中的 Mermaid 围栏图表按严格安全模式渲染为 SVG；正文根据整张 SVG 所有可见图层的联合边界校正 `viewBox` 和固有宽高，宽图通过局部横向滚动查看。不能假设 `g.root` 在所有图型中都代表完整图形，时序图等图型由多个并列图层组成。语法错误时显示错误说明并保留源码。
- Mermaid 全屏查看使用与正文 DOM 隔离的页面内预览层，不调用浏览器原生 Fullscreen API。预览层支持自动适应屏幕、居中显示、缩放按钮、`Ctrl + 滚轮`定点缩放、按住鼠标左键拖动和 `Esc` 退出；滚轮使用非被动原生监听器，防止同时触发浏览器页面缩放。
- 打开或关闭全屏导致正文组件重新渲染时，必须重新应用可见边界校正，不能让 React 写回的 Mermaid 原始 SVG 恢复超高画布。全屏层不得修改正文 SVG、正文滚动位置或页面根元素样式。
- `npm run check:mermaid` 扫描仓库 Markdown 中的 Mermaid 围栏，作为发现旧语法、非完整图表片段和渲染回归的独立检查入口。
- 围栏代码使用 Highlight.js 生成语法 token，并按 VS Code Light+ / Dark+ 色系随主题切换。Markdown 源文件要求每个开始围栏显式声明语言；仓库中无法安全判定的说明块标记为 `text`。为兼容已经导入的旧内容，渲染器只对未声明语言且整体满足代码结构的块保守推断 C、Shell 或 JSON，不对显式 `text`、Mermaid 和中文流程说明进行激进猜测。
- 每章显示规范化知识声明和原文依据；训练题绑定章节与声明。
- 支持上一项、完成并继续、自评、逐级提示、答案核验和训练总结。
- 大厅展示最近三个进行中会话，可以恢复到上次题目。

### 1.3.3\_本地持久化

- 训练会话、答案、提示层级、自评、已揭示内容和完成位置保存在 IndexedDB。
- 输入变更采用 1000 毫秒防抖自动保存，并显示待保存、保存中、已保存或失败状态。
- 保存失败时可以重试或导出当前会话草稿。
- 分类和训练模块保存在 IndexedDB。
- 旧版工作区 `localStorage` 数据首次读取后迁移到 IndexedDB，并删除旧键。
- 用户导入的电子书草稿、章节顺序、候选声明、训练任务草稿和发布状态保存在独立的 IndexedDB 对象仓库。

### 1.3.4\_训练组织

- 训练库已经提供左侧单元目录和右侧训练卡片双栏工作区，目录筛选包含全部后代单元。
- 单元目录支持创建、修改、任意层级组织、同级排序、跨层移动和移入回收站；父级候选排除自身和后代，避免形成层级环。
- 目录和单元同时支持鼠标拖拽与键盘方向键排序；单元可以从右侧卡片直接拖入目录，也可以在目录子项之间前后放置。
- 点击目录中的单元只负责选中并定位右侧卡片，只有右侧单元卡片进入详情。
- 单元归类支持“单一目录”和“多目录”两种全局模式，默认单一目录；多目录模式显示已有归属，切回单一目录时整理重复关系。
- 目录和归类写操作支持页面会话内撤销、重做和快捷键，默认保留 1000 步，可在设置页调整为 1～10000 步。
- 训练模块支持创建、修改、选择多个训练单元、关联多个分类、回收、恢复和合并。
- 工作区支持版本化 JSON 导入和导出。
- 管理操作使用页面内正式表单，不使用浏览器 `prompt()`。

### 1.3.5\_现有系统能力

- 知识来源仍通过受控只读接口打开注册知识源内的原文。
- 电子书导入器支持多文件或整个目录选择、按目录名生成默认书名、顺序调整、目录预览、书名、版本、来源 ID、草稿保存、重新编辑、删除、发布校验和本地阅读。
- 原文阅读模式保留所选 Markdown 正文；专题电子书模式生成可编辑的章节目标、候选知识声明和训练任务草稿，发布前要求逐章人工确认。
- 应用外壳保留版本查询、更新提示和安全更新入口。
- 搜索、领域筛选、空状态、加载状态和基础响应式布局已经提供。
- 设置页已经提供单元归类方式和撤销历史步数设置，并通过工作区存储在本机持久化。

## 1.5\_尚未实现

- 复习调度、到期队列、薄弱项重练和掌握度模型。
- 可筛选、可比较、可导出的训练历史页面。
- 知识源管理页面和来源可用性诊断。
- 数据清理、备份恢复、隐私控制及其他通用设置项。
- 用户置顶会话、多个会话的完整管理和“重新开始”冲突处理。
- 多标签页单写者租约、围栏令牌和只读接管。
- 撤销提示条、永久删除和回收站保留期限。
- 候选声明之间的冲突审查、证据映射、AI 提炼服务和发布到仓库随版本题库的维护者工作流。
- 自动化组件测试、端到端浏览器测试、性能基准和无障碍工具验收。

当前复习、历史和知识源路由只提供边界说明占位页，不属于功能完成。设置页只完成训练库归类和撤销历史两项配置，不能视为通用设置中心已经完成。

## 1.8\_已知风险

`react-router-dom` 固定为 `7.18.1`。当前依赖审计报告 2 个高危项，来自 React Router 的 RSC 模式 CSRF 公告；回路当前是纯浏览器 Vite 应用，没有启用 RSC 或服务端 Action。审计建议的降级版本同时命中更多已披露漏洞，因此没有执行强制降级。后续应跟踪上游安全版本并重新审计。

## 1.9\_下一实现顺序

1. 完成返回大厅前的可等待强制保存和失败决策。
2. 拆分训练会话用例、步骤组件和存储接口，增加单元测试。
3. 实现训练历史和薄弱项复习，使总结页形成闭环。
4. 增加多标签页租约、修订日志和恢复测试。
5. 完成导入预览、冲突处理和事务回滚。
6. 执行真实浏览器、键盘、NVDA、响应式和性能验收。
