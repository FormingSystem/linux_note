# 第1章\_产品导航与交互设计

## 1.1\_目标

回路采用文件编辑器而不是内容平台导航。用户打开窗口后应能立即新建文件、打开文件或打开文件夹；主界面始终围绕资源管理器、编辑标签、Markdown 源码和预览，不存在大厅、训练库、专题电子书、导入发布或阶段解锁。

## 1.2\_窗口布局

```text
标题栏 / 菜单 / 命令入口
├── 当前文件或文件夹名称
├── 全局保存与冲突状态
└── 窗口控制

工作台
├── 左侧边栏
│   ├── 文件资源管理器
│   ├── 搜索
│   └── 当前文档大纲
└── 编辑区
    ├── 标签栏
    └── Typora 式混合 Markdown 编辑面

状态栏
├── 相对路径 / 行列 / 编码 / 换行
├── 保存、备份和外部修改状态
└── Markdown 配置与诊断数量
```

窗口根节点锁定视口高度；资源管理器和混合编辑面分别拥有有界滚动，不用全局滚动条承载工作台。Markdown 默认在同一 CodeMirror 文档中局部源码编辑、其余块实时渲染，不再因窗口宽度切换源码与预览面板。

## 1.3\_欢迎页与打开行为

空窗口只展示：

- 新建 Markdown。
- 打开文件。
- 打开文件夹。
- 最近打开。

“打开文件”进入单文件模式，不显示父目录树；“打开文件夹”显示单根资源管理器。拖放文件或目录到空窗口与对应打开动作相同，不复制内容。

重新打开最近项时，如果路径不存在、目标身份变化或权限不足，保留最近记录并显示“定位 / 从最近列表移除”，不猜测新路径。

## 1.4\_资源管理器

目录按需展开。文件项显示名称、类型、脏状态、外部变化和诊断；只有消歧义时才显示更长相对路径。

上下文命令包括：新建文件、新建目录、重命名、移动到回收站、复制相对路径、在系统文件管理器中显示。移动和删除遵循 [工作区文件操作与数据安全](../engineering/workspace_file_operations_and_data_safety.md)。

资源管理器不是“导入进度”界面。大型目录索引在后台进行，不阻止用户立即展开目录和打开文件；排除或资源限制必须在状态栏可见。

## 1.5\_标签与编辑组

- 单击文件打开普通标签；双击或开始编辑后固定标签。
- 标签圆点表示未保存，错误图标表示保存失败或冲突。
- 同名文件通过最短可消歧义相对路径区分。
- 关闭单个脏标签显示保存、不保存、取消。
- 关闭窗口使用 Hot Exit，下一次恢复为未保存状态。
- 第一阶段支持一个编辑组和一个混合编辑面，不实现侧边预览或任意网格拆分。

限制首版编辑组数量可以避免提前复制 VS Code 的完整布局系统，同时保留最重要的连续 Markdown 写作工作流。

## 1.6\_源码与预览

每个 Markdown 文档默认提供一个 Typora 式混合编辑面：当前光标或选择相交的顶层块显示原始 Markdown，其他块显示当前内存修订的安全渲染。点击渲染块即在原位置进入源码编辑；渲染和源码共享一个滚动容器，不存在两个面板之间的百分比同步。

`Ctrl+/` 切换完整源码模式。该命令只开关 CodeMirror 装饰，不创建第二份正文或撤销历史。Mermaid 在原块位置通过隔离 Frame 渲染；图表工具栏支持 50%～300% 放大、缩小、复位和适合宽度，放大后的滚动限制在图表视口内，“编辑源码”返回该围栏。独立全屏查看器与拖拽平移仍属于后续增强。

## 1.7\_保存与状态反馈

状态不能只依赖 Toast：

| 状态 | 标签 | 状态栏 | 允许动作 |
| --- | --- | --- | --- |
| Clean | 无圆点 | 已保存 | 编辑、另存为 |
| Dirty | 圆点 | 未保存；可显示已备份时间 | 保存、还原、比较 |
| Saving | 圆点 | 正在保存 | 继续编辑、取消自动重试 |
| SaveFailed | 错误 | 失败原因 | 重试、另存为、查看详情 |
| Conflict | 冲突 | 外部版本已变化 | 比较、合并、采用磁盘、另存为 |

“恢复备份已更新”只作为 Dirty 的辅助信息，不能替代“未保存”。自动保存默认关闭；开启后在设置和状态栏可发现。

## 1.8\_搜索、快速打开与大纲

- `Ctrl+P` 按相对路径快速打开当前文件夹内文件。
- `Ctrl+Shift+F` 搜索当前文件夹；单文件模式只搜索当前文件。
- `Ctrl+Shift+O` 打开当前 Markdown 标题列表。
- 工作区标题与链接索引按需建立，未完成时显示进度并允许取消。

搜索结果携带文件 ID、相对路径和源码位置。点击后通过 Main 重新验证文件身份，再打开编辑器；索引路径不能直接成为文件系统权限。

## 1.9\_命令与快捷键

第一阶段至少提供：

| 命令 | 默认快捷键 |
| --- | --- |
| 新建文件 | `Ctrl+N` |
| 打开文件 | `Ctrl+O` |
| 打开文件夹 | `Ctrl+K Ctrl+O` |
| 保存 | `Ctrl+S` |
| 另存为 | `Ctrl+Shift+S` |
| 关闭标签 | `Ctrl+W` |
| 快速打开 | `Ctrl+P` |
| 全局搜索 | `Ctrl+Shift+F` |
| 切换完整源码模式 | `Ctrl+/` |
| 命令面板 | `Ctrl+Shift+P` |

快捷键集中登记并允许用户级覆盖。正文编辑器获得焦点时，撤销与重做只操作 CodeMirror 事务，不触发文件树或窗口历史。

## 1.10\_安全交互

- 远程图片显示被阻止占位，不自动请求网络。
- 外部链接交给系统浏览器前显示规范化域名；HTTP 与异常地址额外确认。
- 根外符号链接显示真实目标和原因，用户必须通过系统选择器显式打开。
- 工作区目录中的设置、脚本和插件不会自动加载，因此第一阶段不提供形式化“信任后执行”按钮。
- 删除只提供移动到回收站；永久删除不作为首版快捷命令。

## 1.11\_无障碍

- 所有资源树、标签、命令、预览切换、诊断和冲突操作可用键盘完成。
- 焦点顺序为标题命令、边栏、标签、编辑器、预览、状态栏；切换区域有明确命令。
- 保存失败和外部冲突使用 `aria-live` 通知，但持续状态仍可聚焦读取。
- 源码与预览同步滚动可关闭，减少运动模式下不强制动画。
- Mermaid 查看器的缩放和平移同时提供按钮与键盘操作。

## 1.12\_验收边界

- 从空窗口到打开文件、编辑、预览、保存的路径不超过一次文件选择和一次保存命令。
- 打开文件夹后立即可浏览首层和按需展开，不等待全目录索引。
- Dirty、已备份、正在保存、失败和冲突不能混淆。
- 单文件与文件夹模式在资源管理器、搜索范围和路径权限上表现不同。
- 源码—预览定位、预览锁定和复杂块旧修订标记可被测试。
- 仅使用键盘可以完成打开、编辑、保存、预览、搜索、关闭和冲突处理。
