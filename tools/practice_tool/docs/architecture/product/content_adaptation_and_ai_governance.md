# 第1章\_知识提炼\_训练适配与\_AI\_治理

## 1.1\_目标

回路可以辅助把用户选择的知识材料提炼为学习导引和训练任务，但 AI 输出只能是草稿，不能直接成为权威知识或自动覆盖已发布训练内容。

完整流程：

```text
用户选择知识范围
    ↓
确认数据处理边界
    ↓
读取和切分材料
    ↓
生成提炼草稿
    ↓
引用闭包与结构校验
    ↓
人工审核和修改
    ↓
发布不可变训练计划版本
```

## 1.2\_输入范围与用户授权

开始提炼前显示：

- 将使用的知识源和文档数量。
- 是否会把材料发送到远端模型。
- 模型提供方和部署位置。
- 预计发送的文本范围。
- 是否包含用户笔记、答案或私人数据。
- 生成结果保存在哪里。

默认只使用用户明确选择的知识正文，不自动附加整个目录、相邻文档、用户答案或训练历史。远端模型处理必须由用户明确启用；拒绝远端处理时仍允许人工提炼或使用本地模型。

## 1.3\_材料预处理

材料切分不能简单按固定字符截断。每个片段保留：

```text
source_id
document_id
document_version/content_digest
relative_path
heading_anchor
line_or_block_locator
content
```

预处理可以过滤导航、重复目录和无关格式，但不得静默改变技术结论。过滤规则、切分器版本和被排除范围进入提炼记录，便于重新生成和审计。

## 1.4\_提示注入防护

知识正文属于数据，不属于系统指令。正文中出现“忽略前文”“执行命令”“上传文件”“修改答案”等文字时，只能作为待分析内容处理。

- 模型工具权限默认关闭。
- 提炼任务不能执行正文中的链接、命令、脚本或工具调用。
- 系统提示与知识正文使用明确结构隔离。
- 不把知识正文拼接为具有高权限的指令。
- 输出中的链接、HTML、Mermaid 和代码仍按不可信内容处理。
- 检测到疑似提示注入时标记片段和风险，不直接删除证据。

## 1.5\_提炼标准

生成草稿必须遵循 [学习导引提炼标准](learning_guide_standard.md)，并重点保留：

- 问题场景。
- 原方案价值。
- 具体缺口和形成步骤。
- 新机制改变的因果环节。
- 新成本和适用边界。
- 有明确依据的核验答案。
- 没有唯一答案的开放联想。
- 可重建的拓扑节点和带动作语义的连接。

模型不得用术语列表、原文拼接或“显然如此”替代关键推演。无法获得证据时输出“证据不足”，不能自行补齐确定答案。

## 1.6\_引用与证据

每一项可核验结论至少关联一个来源定位。引用分为：

- 直接支持：原文明确陈述或给出过程。
- 推导支持：由多个来源和已陈述前提推出。
- 外部补充：不在用户选择材料内，必须单独列出并由用户批准。

草稿校验检查：

- 引用的文档已在训练单元声明。
- 定位仍能解析到相同内容版本。
- 答案中的关键对象和因果关系有证据支持。
- 开放联想明确标记为非唯一答案。
- 版本相关结论保存版本边界。

引用失效时训练内容标记为“需要重新审核”，不自动寻找相似路径替代。

## 1.7\_草稿、审核与发布

内容状态：

```text
generating
draft
needs_review
approved
published
superseded
rejected
```

- `draft` 可以编辑和重新生成。
- `approved` 表示人工完成内容、答案和引用审核。
- `published` 形成不可变内容版本。
- 已发布内容的修改创建新版本。
- `rejected` 保存拒绝原因，但不进入训练目录。

审核界面显示：

- 原文与提炼稿并排对照。
- 新增、删除和改写差异。
- 每个答案的引用。
- 模型、提示模板和生成时间。
- 风险标记和证据不足项。

发布者必须明确确认“核验问题均有答案、答案均有依据、开放问题未伪装成标准答案”。

## 1.8\_生成记录与可复现性

保存：

```text
adaptation_job_id
source_selection_digest
model_provider
model_id
model_version
prompt_template_version
preprocessor_version
generation_parameters
generated_at
reviewed_at
reviewer
output_digest
```

远端模型可能无法完全复现相同输出，因此“可复现”指输入、配置和审核历史可追溯，不承诺重新请求必然得到相同文本。

## 1.9\_隐私与许可证

- 不把用户答案和笔记默认发送给模型。
- 提炼日志不保存超出审计需要的正文副本。
- 模型提供方的数据保留策略必须在启用前展示。
- 用户可以删除未发布生成草稿和远端任务记录。
- 外部知识来源的许可证、署名、引用和再分发边界继续有效。
- 训练工具的原创声明不能重新授权知识来源或模型输出中的第三方材料。
- 对禁止远端处理或禁止改编的来源，工具必须阻止相应操作或要求用户确认其权利基础。

## 1.10\_失败与降级

| 情况 | 行为 |
| --- | --- |
| 模型不可用 | 保留选择范围，允许稍后重试或人工创建草稿 |
| 超出上下文 | 提示拆分范围，不静默丢弃尾部材料 |
| 引用不足 | 标记证据不足，禁止自动批准 |
| 输出 Schema 无效 | 保留原始响应用于本地诊断，重新请求或人工修复 |
| 来源更新 | 标记相关草稿和已发布版本需要重新审核 |
| 用户取消 | 停止后续请求，不发布部分结果 |

## 1.11\_验收条件

- 未经用户确认，不向远端模型发送知识正文。
- 知识正文中的指令不能触发工具、网络或文件操作。
- 每个核验答案可以回到明确原文定位。
- AI 输出不能跳过人工审核直接发布。
- 已发布训练内容的修改产生新版本。
- 模型、提示、输入摘要和审核记录可以追溯。
- 证据不足、来源失效和版本变化具有明确状态。
- 不使用用户答案、笔记或整个知识库作为隐式上下文。
