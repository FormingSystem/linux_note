# 第1章\_学习导引提炼标准

## 1.1\_定位

学习导引不是原文导入、摘要拼接或考试前提纲。它以用户选择的权威材料为证据，重新组织一条适合首次学习的因果主线，使读者先看见问题、参与推演，再进入提示提问、脱稿输出和专业案例。

原文中的重复、闲谈、目录性说明、与本轮主题无关的旁支和未经核验的个人补充不自动进入导引。必要背景可以重写，但不能改变原文技术结论；无法从知识来源支持的结论不得写进标准答案。

## 1.2\_强制结构

每份导引必须包含：

1. 单一明确主题和可观察的学习目标。
2. 能让问题发生的具体场景，而不是先宣布术语。
3. “原方案价值 → 具体缺口 → 缺口形成过程 → 新机制改变处 → 新代价”的主线。
4. 篇幅适当的分段正文，每段只承担一个推演步骤。
5. 至少一个有明确答案的核验问题，问题和答案必须成对出现。
6. 至少一个没有唯一答案的开放联想，并明确它用于迁移思考而非评分。
7. 一项拓扑记忆训练，要求读者重建关键对象以及带动作含义的连接。
8. 指向权威正文的稳定文档 ID 和相对路径。

## 1.3\_问题类型

### 1.3.1\_核验问题

核验问题检查材料中已经建立的事实或因果关系，必须有答案。答案应说明关键原因，不能只给“是”“否”或术语。

### 1.3.2\_开放联想

开放联想用于改变负载、约束或观察角度，例如把内存索引换成页级索引、让输入变得可控、把单线程更新改成多 CPU 并发。它允许多种合理方案，不进入机械对错评分。

### 1.3.3\_拓扑记忆

拓扑记忆不是背关键词列表。节点表示角色、状态或约束，边必须表示动作、所有权、因果或状态流，例如：

```text
对象增长 → 负载因子上升
负载因子上升 → 冲突链增长
冲突链增长 → 查找成本上升
```

只画方框而不写连接语义视为未完成。

## 1.4\_篇幅控制

单份导引默认由 3～6 个短节组成。每节优先在一个屏幕内完成一个推演步骤；复杂主题应拆成多个导引，不得通过堆叠原文段落制造“完整”。判断是否保留内容的标准是：删除它之后，读者能否仍从问题自然推出本轮训练所需模型。

## 1.5\_追溯规则

导引正文是训练工具的提炼内容，知识库正文仍是权威来源。界面必须展示本导引使用的知识源、文档 ID 和相对路径。文件型知识源在受控读取服务完成前至少提供可复制路径；服务完成后允许直接打开注册根目录内的文档，但不得绕过知识源边界访问任意文件。

训练问题引用的文档必须先在所属训练单元声明。内容校验器负责检查引用闭包、必答问题、开放联想和拓扑任务是否完整。

使用 AI 辅助生成时，还必须遵守 [知识提炼、训练适配与 AI 治理](content_adaptation_and_ai_governance.md)。AI 输出只能进入草稿和审核状态，不能直接发布。
