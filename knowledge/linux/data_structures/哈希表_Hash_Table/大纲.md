# 第1章\_哈希表学习路线

读者已经掌握 C 指针、结构体、数组，以及[链表中的对象与成员](../单链表_linked_list/大纲.md)。本专题从按编号查找进入桶和冲突，再研究 Linux 节点、位宽、并发与容量变化。源码版本以[固定索引](../../../../research/source_reading/hash_table/navigation/P01_Linux_6.12_哈希计算源码阅读索引.md)为准，历史路径中的 5.10 不能替代证据。

## 1.2\_版本与交叉入口

当前源码索引覆盖哈希计算、固定桶数组、hlist 节点、RCU 旧路径以及动态表的迁移和接口边界；子系统部分覆盖名称候选、连接引用复核和邻居设备身份，完整模块覆盖固定桶私有生命周期。该范围不等于全部 VFS 或网络协议已重构。具体证据和目标运行限制见[工作记录](../../../../governance/migration/repository_textbook_refactor.md#1.4.15_B03e子系统身份与固定桶完整实验)。各章可信度仍以唯一[评审地图](../../../../atlas/maps/knowledge_review_map.md)为准，本大纲不另建评审台账。

通用锁、发布和回收请进入[同步与异步总纲](../../synchronization_and_asynchrony/大纲.md)及[RCU 专题](../../synchronization_and_asynchrony/synchronization/rcu/大纲.md)；按键范围访问则继续[树结构](../红黑树_rb-tree/大纲.md)。这些入口承担不同任务，不因都出现节点而合并。
