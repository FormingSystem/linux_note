# 第1章\_Linux内核链表

本专题维护 Linux list_head 的基础教材：它是侵入式双向循环链表，节点嵌在业务对象中，头节点作为循环哨兵。目录中的“单链表”沿用既有路径；普通单向表、hlist 与 llist 是不同表示，不能混用接口。

读者具备 C 指针、结构体与函数知识；内核模块实验还需完成[模块构建课程](../../../../engineering/build/kernel_modules/大纲.md)。先用不依赖内核的模型建立拓扑，再进入并发、发布和真实接口。默认不要求读者先掌握 RCU 或原子指令细节。
