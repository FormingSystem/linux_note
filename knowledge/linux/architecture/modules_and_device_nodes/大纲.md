# 第1章\_模块与设备入口大纲

这一组文章连接“源码怎样变成可运行模块”和“应用怎样找到设备”。它保留模块入口与多实例身份的最小模型；构建操作由工程专题维护，字符设备的注册、I/O、等待与生命周期由字符设备专题维护，不再在这里保存另一套长驱动模板。

## 1.1\_沿三个问题进入正文

```mermaid
flowchart LR
    source[已经认识源码与构建产物] -->|先装入一个只打印日志的模块| build[模块构建]
    build -->|为什么没有同名设备节点| entry[代码 服务 路径的区别]
    entry -->|号码怎样接到操作表| registration[字符设备登记与发布]
    registration -->|两个名字是否代表两个对象| identity[多实例身份与组织]
    identity -->|选择内容或数据流契约| implementation[有限窗口与环形流]
```
