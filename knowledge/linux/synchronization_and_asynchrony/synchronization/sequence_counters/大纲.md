# 第1章\_序列计数器专题大纲

## 1.1\_专题定位

序列计数器用“读者先复制、最后验证、失败重试”替换读侧加锁，适合写少读多且快照可以安全丢弃的标量状态。它不是一种轻量万能锁：写者串行化、奇偶代际、内存顺序、不可回滚副作用和对象生命周期缺一不可。

## 1.2\_因果学习链

```mermaid
flowchart LR
    A["读锁阻塞写者"] --> B["允许读者看到临时值"]
    B --> C["用前后代际拒绝坏快照"]
    C --> D["补上写者串行与内存顺序"]
    D --> E["写者可被中断：双副本latch"]
    E --> F["关联锁、RT与生命周期边界"]
```

1. [seqcount/seqlock 读重试快照](P01_seqcount_seqlock_读重试快照机制.md)：接口、基本限制和与锁/RCU 的边界。
2. [一致快照的证明模型](P02_一致快照的证明模型.md)：从坏快照反例推导奇偶代际与 S0～S6。
3. [seqcount 读写路径与内存顺序](P03_seqcount读写路径与内存顺序.md)：把 begin/retry、写侧窗口和屏障映射到 Linux 6.12.20。
4. [seqcount_latch 双副本状态机](P04_seqcount_latch双副本状态机.md)：允许 NMI 等读者中断非原子写过程。
5. [关联锁变体与实时性边界](P05_关联锁变体与实时性边界.md)：解释关联锁只验证什么，以及 PREEMPT_RT 怎样补偿可抢占 writer。
6. [生命周期、误用诊断与选型](P06_生命周期误用诊断与选型.md)：用指针、回绕、长读区和调试证据收束选择边界。
