## 1.1\_从退出责任进入资源接口

起点是C对象、回调与分配释放。先问驱动失败后谁撤销已经成功的步骤，再把这个责任落到设备资源记录，最后按具体子系统查询获取、启停与释放契约。

```mermaid
flowchart LR
    A["失败出口和正常退出重复清理"] -->|"提取成功记录与依赖顺序"| B["P01：资源账本与分组"]
    B -->|"记录正确仍要证明使用者退出"| C["P02：访问窗口与清理顺序"]
    C -->|"跨过内核与用户空间边界"| U["系统软件：事件与设备策略"]
    U -->|"用同一设备分别观察各层"| D["P03：跨层访问案例"]
    D -->|"外壳与资源期限不同时"| E["生命周期集成"]
    C -->|"按需核对具体返回和责任"| Q["API查询与固定源码"]
```
