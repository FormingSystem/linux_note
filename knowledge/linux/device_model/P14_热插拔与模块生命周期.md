# 第14章\_热插拔与模块生命周期

热拔出不是只调用 `remove()`：还要协调新绑定、使用该设备的依赖方、可见入口与旧访问，归还引用后才可能最终 release。不能把“设备已绑定”当成驱动模块被永久加引用；普通模块可以在退出函数中注销驱动并同步解绑设备。文件操作表等路径可能另行持有模块引用，回调与异步活动则需要对应的注销和停机协议。驱动注销撤销登记并解绑设备完成以后，模块还须保证自己负责的其他入口与活动都已退出，才允许代码离场。

需要分别跟踪“设备已注册”“设备已绑定”“对象仍有引用”“驱动模块仍可执行”四种状态，任何一个布尔值都不能代表完整生命期。
