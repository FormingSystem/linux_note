# 第1章\_错误指针专题大纲

本专题从“函数既要交出对象，又要解释失败”出发，建立错误表示、显式传播和资源责任的区别。先修是基本 C 指针、结构体与函数调用；最后一章运行实验还需要已有的[模块构建与部署](../../../../engineering/build/kernel_modules/大纲.md)。

## 1.1\_四次认识变化

```mermaid
flowchart LR
    a[NULL只能表示没有对象] -->|增加失败原因| b[选择返回契约]
    b -->|检查特殊值如何识别| c[编码范围与类型边界]
    c -->|加入可选资源和前序申请| d[返回状态与回收责任分开]
    d -->|改变同一实验的失败点| e[观察探测与释放顺序]
```

| 阅读入口 | 带入的认识 | 本篇解决的问题 | 留给下一篇的问题 |
| --- | --- | --- | --- |
| [取得对象以后，先判断返回了什么](错误指针机制简介.md) | 能读 C 指针 | 对象、NULL、整数状态与错误指针怎样选择 | 特殊值凭什么可识别 |
| [错误值的编码与判定](P02_错误值的编码与判定.md) | 已知道错误是返回值的一种含义 | 32/64 位数值边界，以及检测不能证明什么 | 失败以前取得的资源怎么办 |
| [资源失败与驱动回滚](P03_资源失败与驱动回滚.md) | 会先检查再访问 | 可选缺席、设备管理、probe 和显式回滚各自承担什么 | 怎样观察传播与回收是否按预期发生 |
| [观察返回值与释放顺序](P04_观察返回值与释放顺序.md) | 明确返回与所有权两条线 | 用无硬件依赖的完整模块对照四种结果 | 把相同方法迁移到真实驱动并核对其资源契约 |

## 1.2\_查询与继续阅读

[接口与排错速查](readme.md)用于已经学过机制后的查询，含错误码、跨语言边界和常见误判；它不是另一份教学大纲。[固定版本源码索引](../../../../research/source_reading/error_pointer/navigation/P01_Linux_6.12_错误指针源码阅读索引.md#1.2_按问题进入源码)组织源码模块导读与唯一函数体说明。

回到[字符设备窗口模板](../../../driver_model/character_device/P10_字符设备驱动模板.md)时，应能分别解释分配内存、建立设备类、登记设备号为何采用不同失败判断。设备生命期与 devres 的完整实现继续在[设备模型](../../device_model/大纲.md)中学习，本专题只解释错误路径与资源责任相交的部分。
