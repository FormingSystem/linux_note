# 第1章\_文件操作的学习路线

已完成 misc 和字符设备读写后，继续追问三个问题：两个描述符是否有两个上下文，一次请求的位置属于谁，关掉描述符是否就能释放后备页。本专题从可区分的实验建立这些边界；VFS 的完整路径和通用对象模型仍由相邻专题承担。

## 1.1\_沿对象寿命逐步增加约束

```mermaid
flowchart LR
    a["每次打开的上下文"] -->|"dup 暴露共享引用"| b["P01：flush 与最终 release"]
    b -->|"同一个 file 上可以有独立请求位置"| c["P02：iter 与 pread"]
    c -->|"操作返回后仍有人使用后备对象"| d["P03：映射寿命"]
    d -->|"先选承诺再选择成员"| e["P04：扩展接口边界"]
```

| 章节 | 前置与本次认识变化 | 留下的下一问 |
| --- | --- | --- |
| [一次打开与最后一次释放](P01_一次打开与最后一次释放.md) | 已会 misc；用 dup/fdinfo 观察关闭与最终释放 | 请求位置如何与打开对象分开 |
| [迭代读取与请求位置](P02_迭代读取与请求位置.md) | 已懂复制进度；用 readv/pread 观察两组游标 | 后备数据能否活过 fd |
